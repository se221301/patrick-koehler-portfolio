# Patrick Köhler Portfolio

Static bilingual portfolio website for Patrick Köhler.

## Files

```text
.
├── index.html
├── styles.css
├── script.js
├── README.md
└── assets/
    ├── patrick-portrait-main.jpg
    ├── patrick-portrait-secondary.jpg
    ├── patrick-private-original.png
    ├── patrick-professional-original.jpg
    └── patrick-koehler-cv.pdf
```

## Images

- `patrick-portrait-main.jpg` → prepared crop of the professional suit photo used in the hero section.
- `patrick-portrait-secondary.jpg` → prepared crop of the private photo used in the About section.
- `patrick-professional-original.jpg` → original uploaded suit photo.
- `patrick-private-original.png` → original uploaded private photo.

The website references the prepared crops, so no manual image editing is required.

## Language

English is the default language. EN/DE text is stored in `script.js`. The selected language is saved in local storage.

## GitHub Pages

This is a static site and needs no build step.

1. Create a GitHub repository.
2. Upload all files and folders.
3. Open **Settings → Pages**.
4. Publish from the `main` branch and `/ (root)`.

## Privacy note

The included CV is the uploaded original. Before publishing the site publicly, review the PDF and decide which personal information should remain visible.
